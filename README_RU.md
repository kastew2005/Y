# APEX — Rifters of Aethelgard (обновлённая сборка)

## Что добавлено
- Поле из 3 200 инстансированных травинок за пределами центральной площади.
- Лёгкая shader-анимация покачивания травы от ветра.
- Динамические следы персонажа в траве: появляются при движении вне города, постепенно исчезают; используется ограниченный пул объектов.
- Сохранены исходные меню, персонаж, враги, HUD, мини-карта, погодные эффекты и сенсорное управление.

## Запуск
Откройте `index.html` через локальный веб-сервер или разместите все три файла (`index.html`, `manifest.json`, `sw.js`) на HTTPS-хостинге. Three.js и постобработка загружаются с unpkg CDN, поэтому для первого запуска требуется интернет.

На iPhone удобнее открыть размещённую HTTPS-версию в Safari и добавить её на экран «Домой». Игра рассчитана на альбомную ориентацию.

## Примечание
Это браузерный прототип MMORPG, а не сетевой серверный MMO: синхронизация игроков и аккаунтов не реализована. Производительность зависит от устройства и браузера.
