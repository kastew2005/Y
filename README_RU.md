# APEX — модульный мобильный RPG-прототип

## Запуск
- Для локального запуска используйте любой статический HTTP-сервер; ES-модули и Service Worker не работают корректно при открытии через `file://`.
- Для iPhone опубликуйте папку на HTTPS-хостинге (например, GitHub Pages) и откройте страницу в Safari.
- Three.js загружается с unpkg CDN, поэтому при первом запуске требуется интернет. После кэширования Service Worker сохраняет локальные файлы проекта, но не гарантирует офлайн-кэш CDN-модуля.

## Структура
- `index.html` — вход и HUD.
- `css/main.css`, `css/hud.css` — адаптивный интерфейс и safe areas.
- `js/engine.js` — сцена, освещение, цикл, адаптивный pixel ratio.
- `js/graphics.js` — материалы и renderer.
- `js/world.js` — рельеф, лес, камни, рунический лагерь, инстансированная трава.
- `js/character.js` — процедурный персонаж, броня и базовая анимация.
- `js/controls.js` — сенсорный мультитач, движение, обзор и действия.
- `js/ui.js` — HUD, мини-карта, чат и пауза.
- `legacy-apex.html` — исходная версия из переданного архива без модульного рефакторинга.

## Реалистичные ограничения
WebGL в Safari не является прямым Metal API. Браузер может использовать Metal через системный графический слой, но приложение не управляет Metal напрямую. WebGPU не используется как обязательная зависимость из-за различий поддержки браузеров. PBR-материалы здесь процедурные и не содержат готовых внешних наборов albedo/normal/roughness карт. Цель — стабильный прототип; гарантировать 60 FPS на каждом iPhone нельзя, поэтому разрешение динамически уменьшается при падении частоты кадров.
